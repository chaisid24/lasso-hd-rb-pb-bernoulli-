This directory contains two folders output/output-heteroskedastic-case and output/output-homoskedastic-case, containing the processes R output after running the relevant R codes and also the outputs received by using the plotting codes. These files are uploaded for displaying our results in details. These files are not meant for use.

The file names used in these directories are described in the relevant R code files.

Any interested user can generate their own data using the data generation code, run the relevant R code for RB/PB based CIs and obtain desired output, and then use the plotting code for obtaining plots.
