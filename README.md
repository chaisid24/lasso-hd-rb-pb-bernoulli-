This Github repository is created to store code, data and outputs used in the Simulation study presented in the article, 

"Bootstrapping LASSO estimators under variable selection consistency in high dimensions and some higher order refinements"

by 

Debraj Das, Arindam Chatterjee and Soumendra N. Lahiri, 

(which has been submitted to the "Bernoulli" journal for possible publication).

The code folder contains all relevant R code. The code files have been commented in details to explain the functioning of the code (except the code files for plotting, which do not require detailed explanation). This includes code for data generation, homoskedastic errors case (for RB, PB, Oracle and Debiased Lasso based CIs), heteroskedastic errors case (only for PB, Oracle and Debiased Lasso based CIs) and code for plotting figures (displayed in the main article and supplementary materials file) for both types errors.

The data folder contains the data sets used in the simulation study presented in the article. They include the Monte-Carlo data sets for homoskedastic errors case (both error types), and heteroskedastic errors case (both error types). 

The output folder contains some .Rdata files which are outputs generated from the code files and .pdf files (showing plots). They are split into two folders: output/output-homoskedastic-case and output/output-heteroskedastic-case, each for two types of errors.

Each folder contains detailed description of the files within them.
