# Description of data sets stored in this directory

yx-all-n-150-p-500-true-beta-5.Rdata 

This is the Monte-Carlo data set for n = 150, p = 500. It consists of 500 data sets, each for two types of errors cdf (see code/data-gen-code-all.R for details) and for both homoskedastic and heteroskedastic errors.

yx-all-n-300-p-500-true-beta-5.Rdata 

This is the Monte-Carlo data set for n = 300, p = 500. It consists of 500 data sets, each for two types of errors cdf (see code/data-gen-code-all.R for details) and for both homoskedastic and heteroskedastic errors.

These two data sets were used in our simulation study.
